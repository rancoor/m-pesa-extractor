📋 Uploading Bank Statements to Dynamics 365 Finance & Operations

This guide will walk you through the process of importing M-Pesa statement files (Header and Lines) into D365 Finance and Operations using Data Management.

Step 1: Access Data Management

1
Navigate to Data Management workspace

In D365 F&O, go to: Workspaces > Data Management

Step 2: Create Import Project

2
Create a new import project
  • Click on Import tile
  • Enter a project name (e.g., "M-Pesa Statement Import")
  • Select Excel as the source data format
  • Click Create

Step 3: Add Header Entity

3
Add Bank Statement Header entity
  • Click Add file
  • In the entity name field, search for Bank statement header
  • Select the entity from the dropdown
  • Upload the M-Pesa-Header.xlsx file
  • Click Upload and add

💡 Tip: Ensure the field mapping is correct by clicking View map. The system usually auto-maps fields, but verify that STATEMENTID, BANKACCOUNT, CURRENCY, etc., are properly mapped.

Step 4: Add Lines Entity

4
Add Bank Statement Lines entity
  • Click Add file again
  • Search for Bank statement lines
  • Select the entity from the dropdown
  • Upload the M-Pesa-Lines.xlsx file
  • Click Upload and add

⚠️ Important: Always import the Header file BEFORE the Lines file. The lines depend on the header being present in the system.

Step 5: Import Data

5
Execute the import
  • Review the entities in your import project
  • Ensure the sequence is correct (Header first, then Lines)
  • Click Import button
  • Wait for the import to complete

Step 6: Validate the Import

6
Check import status and validate data
  • Click on the execution details to view the status
  • Check for any errors or warnings
  • Review the Staging data if needed
  • Navigate to Cash and bank management > Bank statements
  • Verify that your M-Pesa statement appears in the list
  • Open the statement and check all details are correct

Step 7: Reconcile the Statement

7
Perform bank reconciliation
  • Go to Cash and bank management > Bank accounts
  • Select the MPESA bank account
  • Click Reconcile > Reconcile account
  • Match the imported statement lines with bank transactions
  • Mark lines as matched
  • Post the reconciliation when complete

💡 Best Practice: Always validate your statement before posting. Check that transaction amounts, dates, and references match your actual M-Pesa statement.

❓ Common Questions

Q: What is the Opening Balance field for?

The opening balance is the account balance at the start of the statement period. This should match the closing balance from your previous statement. If this is your first statement, enter the initial account balance.

Q: Where does the Closing Balance come from?

The closing balance is automatically extracted from your M-Pesa statement file. Look for a row labeled "Closing Balance" in your Excel file.

Q: What if the import fails?

Common reasons for import failures:

  • Incorrect file format - ensure you're using the generated Excel files
  • Duplicate Statement ID - each statement must have a unique ID
  • Missing required fields - check the field mapping in D365
  • Bank account doesn't exist - ensure MPESA bank account is set up in D365

Q: Can I reprocess the same statement?

Each time you process a statement, it generates a unique Statement ID based on the timestamp. However, you should avoid uploading duplicate statements to D365 to prevent reconciliation issues.

Q: How do I set up the MPESA bank account in D365?

Go to Cash and bank management > Bank accounts > Bank accounts and create a new account with:

  • Bank account number: MPESA
  • Currency: KES
  • Account type: Bank
  • Main account: Link to appropriate ledger account

Q: What Excel format does M-Pesa provide?

M-Pesa typically provides statement downloads in Excel format (.xlsx) with transaction details including date, description, paid in amounts, withdrawn amounts, and balance information.

🛠️ Troubleshooting

Error: "Bank account not found"

Solution: Create the MPESA bank account in D365 F&O before importing statements.

Error: "Duplicate Statement ID"

Solution: This statement has already been imported. Check the History page to see previously processed statements.

Balances don't match

Solution: Verify that:

  • The opening balance entered matches your previous closing balance
  • The closing balance was correctly extracted from the statement
  • All transactions were properly imported

📞 Need More Help?

If you encounter issues not covered in this FAQ:

  • Check the History page to review previously processed statements
  • Verify your M-Pesa statement file format
  • Contact your D365 system administrator for assistance with Data Management
